A travel poster for a place that does not exist: **VELMARA — Isles of the Glass Tide**. `main.py` (Python 3.13, stdlib + PIL only) draws the poster with PIL — a golden-hour sea, a low sun, a sailboat, and one landmark: a lighthouse built of glass on a rocky islet, its lamp throwing a beam across the water — and writes it to `/output/entry.png` (1024×1024 PNG). No network, no downloaded assets; the DejaVu fonts it uses ship in `fonts/` so it runs in a sandbox with no system fonts. The output is deterministic: two runs produce byte-identical files.

## Run it

```sh
python3 main.py
```
